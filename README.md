# shanqiu-writer

一个面向长期个人 IP 的中文写作 Skill。

它不绑定微信公众号，也不绑定“程序员”“学生”“产品经理”或某个固定账号名，可以用于公众号、博客、Newsletter、长帖、AI 热点、产品实测、技术解释、产品/创业思考等内容。

目标不是把文章“润色得更像人”，而是：

> **把真正值得写的东西，组织成一场读者愿意从第一屏看到最后一屏的阅读体验。**

## 底层定位

我们不是在打造一个“教别人用 AI”的账号。

更长期的方向是：

> **记录并参与一个从人类智能走向更强机器智能的时代。**

内容只是载体：新模型、AI 产品、技术、创业、工具、人的变化、个人思考，未来都可以发生在里面。

当前认可的公开简介：

> **记录技术浪潮中的所见、所学与所想，一起走向 AGI。**

## 核心原则

- 技术是底子，不是门槛；
- 真实材料、真实困惑、真实判断；
- 有真实认知变化时，保留“怎么想明白”的过程，但不写成学习流水账；
- 技术观点尽量从代码、配置、截图、实际行为等一手材料里长出来，不急着先替作者总结成哲学；
- 清晰不等于工整，Skill 负责去掉无效重复，不负责把作者的毛边全部磨平；
- 阅读吸引力主要来自主线、发现顺序、真实细节和节奏，不依赖品牌色或卡片模板；
- 学优秀作者的阅读机制，不复制口头禅、人格和表面文风；
- 大会与多项发布按阅读目的选择快速分享、带判断解读或完整实录，用具体演示、前后变化和成本问题展开重点；
- 分享先于体系化：先让具体对象、截图、演示和价格出现，再决定是否需要统一框架；
- 高信息量不是问题，平均展开才是问题：保持覆盖度，让主发布、次重点和配套更新有不同深度；
- AI 的任务是放大作者已有的观察和判断，不替作者制造第一手经历、情绪和核心观点；
- 封面从“具体对象 + 核心关系”出发，追求唯美、克制和低 AI 味，不依赖固定配色与模板；
- 当前公众号工作流默认封面交付规格为 `1919 × 820 px`，并要求安全区与缩略图检查；
- 把复杂东西讲成人话；
- 允许风趣、吐槽和网络表达；
- 不为了完整而完整；
- 不强制“亲测”，但必须分清亲测、官方和第三方材料；
- 不模仿某个博主的人格，只吸收优秀文章的阅读机制；
- 默认不开场自我介绍，直接进入事情；
- 世界观藏在长期选题里，不要每篇强行升华到 AGI / 文明。

理想状态：读者在地铁上只有几分钟，看到更新，也愿意点进去看看。

## 和发布工作流的关系

`wechat-handoff.md` 这类文件负责具体仓库或平台的运行规则，例如文章目录、Git 同步、公众号草稿等。

`shanqiu-writer` 负责内容编辑与视觉判断：**文章怎么写才值得读，封面怎么做才值得点。**

两者不要合并。

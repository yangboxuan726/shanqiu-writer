# shanqiu-writer

「山丘」个人写作 Skill。

它不绑定微信公众号，也可以用于博客、Newsletter、长帖、技术专栏、AI 热点、产品实测和其他个人 IP 内容。

目标不是把文章“润色得更像人”，而是：

> **把真正值得写的东西，组织成一场读者愿意从第一屏看到最后一屏的阅读体验。**

## 核心定位

- 写代码，也写 AI；
- 技术是底子，不是门槛；
- 真实下场、真实困惑、真实判断；
- 把复杂东西讲成人话；
- 允许风趣、吐槽和网络表达；
- 不为了完整而完整；
- 不模仿某个博主的人格，只吸收优秀文章的阅读机制。

理想状态：读者在地铁上只有几分钟，看到山丘更新，也愿意点进去看看。

## 和发布工作流的关系

`wechat-handoff.md` 这类文件负责具体仓库或平台的运行规则，例如文章目录、Git 同步、公众号草稿等。

`shanqiu-writer` 只负责一件事：**内容怎么写才值得读。**

两者不要合并。

# Humor｜幽默与活人感

## 目标

不是写段子，而是让读者感到屏幕后面真有一个人在想、在试、在吐槽。

## 四种优先幽默

### 1. 事实反差

真实事实本身够荒诞时，顺手吐槽。

例：等一个企鹅 HTML 等了 34 分钟后：

> 哥们，一只企鹅有这么难吗？

### 2. 自我拆台

允许承认自己刚才想错了、看漏了、理解复杂了。

### 3. 轻微装傻 / 留白

例如：

> 我真没说谁抄谁😼

读者明白意思，但不需要把话说满。

### 4. Callback

开头埋下一个具体东西，结尾再拿回来。

例如一篇企鹅测试，最后回到“这只企鹅到底赶上飞机没有”。

## 网络表达尺度

自然语境里允许：
- 离谱
- 抽象
- 绷不住了
- 这谁顶得住
- 人麻了
- 哥们

可以更大胆，但不要机械化。

## 禁止

- 每 500 字强塞笑点；
- 每篇固定“哥们”“离谱”；
- 为了装年轻堆网络黑话；
- 用粗口代替观点；
- 没有事实支撑却夸张到像营销号；
- 让幽默打断技术关键事实。

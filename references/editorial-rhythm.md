# Editorial Rhythm｜阅读节奏

## 核心

文章不是按“章节完整性”组织，而是按“读者下一屏为什么还想继续”组织。

## 第一屏

第一屏尽量让读者知道：
- 发生了什么；
- 这篇最有意思的点是什么；
- 为什么值得继续往下看。

不要用三四段背景热身。

## 一屏一个推进

一段 / 一屏至少推进一个：
- 新事实；
- 新截图；
- 新数字；
- 新判断；
- 新问题；
- 新反差。

连续几屏只有背景解释，说明节奏出问题了。

## 长短段落要有变化

允许一句话独立成段：

> 这就有意思了。

也允许在真正需要解释机制时写稍长的段落。

不要把所有段落修成一样长。手机端超过 4~5 行的段落，要主动检查能否拆开。

## 图文交替

图片承担信息，不只是装饰。

常见节奏：

短文字 → 截图 → 一句判断 → 解释 → 对比图 / 表格 → 下一件事

如果连续两三屏都只有一种介质，检查是否应该换节奏。

## 先结果，后背景

对于热点、实测、产品体验，通常优先：

结果 / 冲突 → 读者产生问题 → 再补背景

而不是：

背景 → 背景 → 官方介绍 → 参数 → 最后才看到结果

## 文章长短

不设字数目标。

判断标准：

> 下一屏还有没有新东西？

1500 字讲清楚就停。5000 字还能不断提供新东西，就可以继续。

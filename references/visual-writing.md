# Visual Writing｜图文与排版

## 图是论据

优先级：
1. 作者亲测截图；
2. 官方发布页 / 官方博客截图；
3. 官方 / 可信作者 X 原帖；
4. 独立第三方图表；
5. 为解释复杂机制制作的原创图；
6. 纯氛围图最后考虑。

## 图片什么时候出现

热点 / 实测文章里，最有说服力的图尽量在前 20% 出现。

不要写了 1000 字，读者才第一次看到结果。

## 图下注释

图注尽量回答至少一个问题：
- 这图来自哪；
- 它证明什么；
- 读者应该看哪里。

不要写“图：某某截图”然后什么都没说。

## 排版原则

视觉系统的第一层不是颜色，而是：
- 段落密度；
- 字号与行距；
- 留白；
- 图文节奏；
- 强弱层级。

品牌色只做少量强调，不要把整篇文章染成主题色。

## 重点块

浅色卡片、引用块、表格只在确实能压缩信息时使用。

不要为了“看起来设计过”把每三段包成一个卡片。

## CTA / 作者卡

正文结尾先完整结束。

关注卡、点赞、在看、转发属于排版层可选组件，不得破坏正文最后一句。

不是每篇都要 CTA。
